One command.

Files, inline code, or stdin. Save a PNG and get structured diagnostics back.

agent-render render card.tsx

In the agent’s context.

The MCP tool returns the image directly. Look, edit, render again.

agent-render mcp

Ready for the next call.

Keep Chromium warm with the local HTTP server. Works with curl, too.

agent-render serve
